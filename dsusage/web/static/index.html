① 登录态（userToken）

如何获取 userToken？（点击展开）
  1. 用 Chrome/Edge 登录 platform.deepseek.com，打开用量页 platform.deepseek.com/usage。
  2. 按 F12 打开开发者工具 → 切到 Console（控制台）。
  3. 粘贴并回车执行：
    copy(JSON.parse(localStorage.getItem('userToken')).value)
    Token 已复制到剪贴板，粘贴到上方输入框即可。
  4. Token 即登录会话，泄露等同于账号泄露；请妥善保管，仅在可信环境使用。
